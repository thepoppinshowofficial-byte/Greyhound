## Affiliate setup
Add your approved Greyhound affiliate/tracking URL to `site.js`:
`const AFFILIATE_LINK = "YOUR_GREYHOUND_AFFILIATE_LINK";`

All CTA buttons marked with `data-affiliate` will use that URL.
